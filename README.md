# Эмулятор фискального регистратора

Java-приложение для эмуляции аппаратуры фискального регистратора Штрих-М-01Ф, предназначенное для тестирования прошивок.

## Архитектура устройства

### Основные компоненты на основе документации:

- **Процессор:** LPC1778FBD208 (NXP) - ARM Cortex-M3, 120 МГц, 512KB Flash, 64KB SRAM
- **Фискальный накопитель:** AT91SAM7S256 (Atmel) - ARM7TDMI, 55 МГц, 256KB Flash, 64KB SRAM
- **Сетевой контроллер:** LAN8720A (Microchip) - Ethernet 10/100 Mbps
- **Драйвер двигателя:** DRV8800PWPR (TI) - H-bridge драйвер
- **Операционные усилители:** OPA347SA (TI)
- **Память:** R1LV0408DSA-5SI (Renesas) - 4Mbit SRAM
- **Регуляторы напряжения:** TPS1117, TPS27081A, TPS54231D, TPS3613-01DGSR (TI)
- **Интерфейсы:** TRS3232ECPWR (TI) - RS-232, 74HCT244D (NXP) - буферы

## Возможности эмулятора

- **Эмуляция процессора**: LPC1778FBD208 (ARM Cortex-M3) с базовым набором команд Thumb-2
- **Эмуляция памяти**: 512KB Flash, 64KB SRAM, порты ввода-вывода
- **Эмуляция контроллеров**: Принтер, фискальный накопитель, датчики, питание
- **Протокол ФН**: Реализация протокола обмена с фискальным накопителем
- **GUI интерфейс**: Удобное управление и мониторинг состояния

## Архитектура эмулятора

### Основные компоненты

- **CortexM3Emulator**: Эмулятор процессора LPC1778FBD208 (ARM Cortex-M3)
- **MemoryManager**: Управление памятью (512KB Flash, 64KB SRAM, I/O)
- **ControllerManager**: Координация всех аппаратных контроллеров
- **FiscalStorageEmulator**: Эмулятор фискального накопителя AT91SAM7S256
- **PrinterEmulator**: Эмулятор термопринтера
- **EmulatorGUI**: Графический интерфейс пользователя

### Структура проекта

```
src/main/java/com/emulator/fphardware/
├── MainApp.java                 # Главный класс приложения
├── cpu/

├── memory/

├── controllers/
│   ├── ControllerManager.java  # Менеджер контроллеров

│   ├── SensorController.java  # Контроллер датчиков
│   └── PowerController.java   # Контроллер питания
├── fn/

├── printer/
│   └── PrinterEmulator.java   # Эмулятор принтера

    └── EmulatorGUI.java       # GUI интерфейс
```

## Сборка и запуск

### Требования

- Java 17 или выше
- Maven 3.6+

### Сборка проекта

```bash
mvn clean compile
```

### Запуск приложения

```bash
mvn javafx:run
```

Или запустить из IDE класс `com.emulator.fphardware.MainApp`

## Использование

### Загрузка прошивки

1. Нажмите кнопку "Загрузить прошивку"
2. Выберите файл прошивки в формате *.bin*
3. Прошивка будет загружена в ROM память

### Управление питанием

- **Включить/Выключить**: Управляет питанием всего устройства
- При выключении питания все контроллеры сбрасываются

### Управление состоянием

- **Крышка корпуса**: Открыта/закрыта
- **Рулон бумаги**: Присутствует/отсутствует
- **Бумага**: Присутствует/отсутствует
- **ФН подключен**: Подключен/отключен

### Окно чека

Отображает данные, выводимые на принтер. Поддерживает:
- Текстовую печать
- Управление форматированием
- Перевод строки и страницы

### Системный лог

Показывает события системы и отладочную информацию в реальном времени.

## Протокол ФН

Эмулятор поддерживает базовые команды ФН:

- `GET_STATUS` - Получить статус
- `GET_SERIAL` - Получить серийный номер
- `GET_VERSION` - Получить версию прошивки
- `OPEN_CHECK:тип` - Открыть чек
- `CLOSE_CHECK:сумма:налог` - Закрыть чек
- `OPEN_SHIFT` - Открыть смену
- `CLOSE_SHIFT` - Закрыть смену

## Разработка

### Добавление новых команд CPU

В классе `CpuEmulator` в методе `executeInstruction()` добавьте обработку новых опкодов.

### Добавление новых контроллеров

1. Создайте класс контроллера в пакете `controllers`
2. Добавьте его в `ControllerManager`
3. Определите порты ввода-вывода в `IoPorts`
4. Обработайте прерывания в `InterruptVector`

### Расширение протокола ФН

В классе `FiscalStorageEmulator` в методе `processCommand()` добавьте обработку новых команд.

## Конфигурация

### Частота процессора

По умолчанию установлена 12 МГц. Можно изменить в `CpuEmulator.CPU_FREQUENCY`.

### Размеры памяти

- ROM: 64KB (можно изменить в `MemoryManager.ROM_SIZE`)
- RAM: 32KB (можно изменить в `MemoryManager.RAM_SIZE`)
- I/O: 256 байт (можно изменить в `MemoryManager.IO_SIZE`)
